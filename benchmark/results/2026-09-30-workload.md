## Live

`live.py --workload --per-category 1 --modes off on --repeat 3` runs the same categories with
`claude -p`, paired off/on per repetition: success, turns, output tokens, uncached / cache
write / cache read input tokens, billed cost, search and build/test calls, tool-output tokens,
re-searches (a search repeating or narrowing an earlier pattern) and unchanged test/build reruns,
with a 95% bootstrap interval per metric and a per-category table. `--tasks FILE --repo-dir DIR`
runs your own tasks (e.g. arvis_code). Smoke run here (2 tasks x off/on, 1 rep, $0.65):
harness works end to end (patch worktrees, build-call and cache accounting); too small for any
conclusion. Run-to-run noise is ~20%, so a cost verdict needs >= 3 reps over >= 10 tasks.
